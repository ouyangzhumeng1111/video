# 《原来，你对谁都这么说》TradeMind SDR · 竖屏职场喜剧（60 秒）

销售给每家客户都发“专门为您做的”方案，直到三位采购在群里把截图放到了一起；老板一句“你到底定制了什么？”，换来一句“公司名……我都改了”。TradeMind SDR 让他第一次真正看了客户：找到匹配企业，看到联系依据，写出说到点上的邮件，第二天就有了回复。

## 做法：屏幕叙事

整个故事发生在手机屏幕上：邮件、群聊、私信、TradeMind SDR、文件夹。画面全部本地渲染，不用视频生成服务，文字、界面和动画都清晰可控。

| 时间 | 场景 | 屏幕上 |
|---|---|---|
| 0–6 秒 | 林悦（启衡精工）收到邮件 | 《为贵司定制的合作方按》，错字只埋不点破；销售的声音：“研究了贵司的业务，这份方案，是专门为您做的。” |
| 6–9 秒 | 陈刚、周敏收到同一封 | 同样的构图、同一位置的错字；同一条录音重复，第三次说到“专门为您——”直接切走 |
| 9–24 秒 | 三人的展会群聊 | 林悦发截图和语音炫耀；陈刚“正在输入”停了一下，发出自己那份，分屏对比只差公司名；周敏：“连错别字都一样。”音乐骤停；她把三张截图拼起来，圈出同一个错字；群里没人说话 |
| 24–34 秒 | 老板私信销售 | 拼图 + “客户发来的。” + 语音“你到底定制了什么？”；销售按住说话：“公司名……我都改了。”；老板“正在输入”出现又消失；销售打出“其实我”又删掉；老板发来 TradeMind SDR |
| 34–45 秒 | TradeMind SDR | 工业连接器 → 无人机制造工厂 → 翔屿无人机制造（匹配 96%）→ 联系依据：官网动态“新增无人机生产线” → 写邮件时习惯性打出“这份方案是专门为您……”，停住，删掉，换成三句针对性的话 → 发送；旁白：“先了解客户，再开口。” |
| 45–55 秒 | 次日 | 赵工读邮件、看产品资料，边打边念：“我们正在选连接器。发份规格书，技术看一下。”；销售马上勾选规格资料；老板：“好。” |
| 55–60 秒 | 落版 | 改个公司名，不叫懂客户。 / TradeMind SDR / 找对客户，说到点上。 + logo |

## 声音

- 台词 7 句：Runway Seed Audio 按场景和语气演绎（`audio/make_lines.py`），销售两句用同一个声音（第二句以第一句为参考）；语音识别核对每个字（“发份”用 medium 模型复核）。
- “专门为您做的”的两次重复直接剪自第一句录音，连呼吸都一样。
- 配乐和音效全部程序生成（`audio/sound_design.py`）：轻快的职场喜剧节奏，周敏说完“连错别字都一样”音乐骤停（干停，没有混响尾巴），老板那场只有房间底噪，TradeMind SDR 打开时音乐重新进入，落版最后一个轻快重音。
- 语音消息带一点手机外放的音色，旁白干净；对白比音乐高约 8 dB。

## 重新生成

```bash
cd tailored_ad/audio
python3 make_lines.py takes L1 --n 2      # 生成台词（Runway，需 RUNWAYML_API_SECRET）
python3 make_lines.py score L1            # 语音识别 + 语速/音高/响度
python3 make_lines.py pick L1 1           # 选用，写入 lines/ 和字级时间
cd ../render && npm install               # playwright-core，使用系统 Chromium
node render.mjs stills 2,12.5,38.8        # 抽帧检查
node render.mjs events                    # 导出声音提示点 output/events.json
node render.mjs video                     # 画面 output/picture_4k.mp4
cd ../audio && python3 sound_design.py    # 配乐 + 音效 + 对白 -> output/mix.wav
```

画面和声音共用 `render/film.js` 里的同一条时间线：改了时间，重新导出 `events.json` 再跑 `sound_design.py`，声音会跟着走。
