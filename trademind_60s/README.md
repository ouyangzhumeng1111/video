## 配音（v2）

- **模型**：Fun-CosyVoice3-0.5B（阿里 FunAudioLLM，Apache-2.0，可商用），用自然语言指令控制语气：「自信有力、语速偏快、节奏明快、富有感染力的广告旁白语气」，语速 1.15；品牌句用「明亮、有力量、充满信心的品牌口号语气」，语速 1.05。
- **音色**：男声取自 CosyVoice-300M-SFT 自带的「中文男」（Apache-2.0），女声取自 CosyVoice 官方示例参考音。参考音只决定音色（`audio/voices/`），语气由指令决定。
- **挑选**：每句生成 2 个版本，全部用 SenseVoice 语音识别回写校对，按准确度和音高起伏选。8 句全部识别正确，唯一差异是同音字「背调/被调」。
- 我无法试听，声音听感请您确认；如果想要别的音色，只要换一段 3–10 秒的参考音就能重新生成。正式投放也可以请真人按下表的时间点录制，每句存成 `output/takes/<voice>_<段号>.wav` 后运行 `build.sh`，剪辑会自动跟着新录音调整。

## 剪辑与配乐如何跟随配音

- `audio/timeline.py`：每段时长 = 进入留白 + 旁白 + 0.6 秒换气，向上取整到 120 BPM 的半拍（0.5 秒），并设每段最短时长保证画面看得清；品牌段固定 7 秒，保证落版后静止 3 秒。结果写在 `output/timeline.json`。
- 画面按原 60 秒设计时间线制作，渲染时按段线性映射到新时间线（`render/js/main.js`），字幕卡、转场、音效点位同步映射。
- 配乐（`audio/make_music.py`，程序原创合成，无版权问题）在新时间线上重新生成：0–10.5s 低沉电子氛围，10.5s 起节奏进入，22s 起弦乐，28s 起弦乐旋律，37.9s 起渐强，42.5s 画面转暖白时解决到明亮的 D 大调并加重音。旁白出现时音乐自动压低约 7.5 dB。

## 需要您知道的限制

- **画面是程序化 3D 动态图形，不是写实视频**：用 three.js 实时 3D 加信息可视化逐帧渲染。如需写实镜头，可把原提示词中各段的「画面 / 配图」交给视频生成工具出素材，再替换 01、03、08 段背景。
- **界面都是概念界面，全部标注「流程示意」**（右上角，约 13.9–39.4s）；拿到脱敏后的真实系统截图可替换 04–07 段面板内容。
- **宣传口径**：没有业绩数字、客户数量、增长率或成交保证；报价是「报价协同 / 草稿」，关键动作由销售确认；纠错是「经复核后采用」。示例企业统一用「示例客户 A / 候选企业 B–E」。
- **Logo** 为深蓝色，放在深蓝画面上几乎看不见，所以只用在片尾暖白落版上，未改色（`assets/logo_rgba.png`，回贴白底与原图最大误差 5/255）。

## 目录与重建

```
assets/     logo 原图与去底 PNG
render/     逐帧渲染器：index.html + js/（main 时间线与映射、compositor 合成、overlay 字幕与落版、scenes/ 八段场景）
            render.mjs：无头 Chromium 驱动，逐帧截图送入 ffmpeg
audio/      narration.py 旁白、分段与语气要求；make_vo_cosyvoice.py 生成配音；assemble_vo.py 定时间线与字幕；
            timeline.py 时间线；make_music.py 配乐与音效；mix.py 混音；voices/ 参考音
build.sh    一键重建（配音 → 时间线 → 配乐 → 混音 → 画面 → 两版成片）
output/     成片、字幕、时间线、配音分句（takes/）
```

生成新配音需要 CosyVoice 代码与模型：`COSYVOICE_SRC` 指向 Hugging Face Space `FunAudioLLM/Fun-CosyVoice3-0.5B` 的代码（CPU 运行时需把其中写死的 `.cuda()` 改为自动选择设备），`COSYVOICE_MODEL` 指向模型 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512`。已有 `output/takes/` 时 `build.sh` 直接复用，不需要模型。

修改文字：屏幕字幕在 `render/js/overlay.js` 的 `CAPTIONS`，旁白在 `audio/narration.py`，各段画面在 `render/js/scenes/`。预览单帧：`cd render && node render.mjs --stills 12.5,30 --outdir ../output/stills`（时间为新时间线）。
