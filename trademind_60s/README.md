## 制作方式与需要您知道的限制

- **画面是程序化 3D 动态图形，不是 AI 生成的写实视频。** 这个环境里没有可调用的文生视频/文生图模型，所以用 three.js 实时 3D（地球、海面与货船、工厂、轴承金属材质、点阵地图）加信息可视化逐帧渲染。风格统一、元素精确可控，但「真实工业场景」是风格化呈现。如需写实镜头（太空地球、真实货轮、真实工厂），可以把原提示词中各段的「画面 / 配图」交给视频生成工具出素材，再替换 01、03、08 段的背景层。
- **界面都是概念界面，全部标注了「流程示意」**（右上角，17.6s–52.9s）。拿到脱敏后的真实系统截图后，可以直接替换 04–07 段的面板内容。
- **宣传口径**：没有出现任何业绩数字、客户数量、增长率或成交保证；报价是「报价协同 / 草稿」，关键动作都由销售确认；纠错是「经复核后采用」，历史可查。示例企业统一用「示例客户 A / 候选企业 B–E」，避免与真实公司重名。唯一的数字是示例产品的标准规格（6205：内径 25 / 外径 52 / 宽 15 mm）。
- **Logo**：附件 logo 为深蓝色，放在深蓝画面上几乎看不见，因此只用在片尾的暖白落版上，并且没有改色。去白底用的是逐像素反混合，回贴白底与原图最大误差为 5/255（`assets/logo_rgba.png`）。
- **旁白是离线 TTS 配音（占位质量）**：Kokoro v1.1-zh 模型（Apache-2.0，可商用）的一个低沉男声（sid 60，语速 0.94）。每句都用 SenseVoice 语音识别回写校对过，剩余差异只是同音字（数据/术据、协同/携同、背调/被调）。第 7 句为了把「你的」「复核」读清楚，只在合成时加了一个逗号、语速调到 0.90，字幕文字不变。正式投放建议请真人配音员按 `output/vo_timing.json` 的时间点录制替换，后续步骤不变。我无法试听音频，声音的听感需要您确认。
- **音乐是程序原创合成**（`audio/make_music.py`），没有版权问题：0–13s 低沉电子氛围（D 小调持续音），13s 起加入节奏，29s 起加入弦乐，37s 起弦乐旋律，51.6s 起渐强，56.2s 落版时解决到明亮的 D 大调并加重音。旁白出现时音乐自动压低约 7.5 dB。
- 4K：当前按 1080p 渲染。渲染器支持 `--dpr 2` 直接输出 3840×2160，耗时约为 4 倍。

## 目录

```
assets/     logo 原图与去底 PNG
render/     逐帧渲染器：index.html + js/（main 时间线、compositor 合成、overlay 字幕与落版、scenes/ 八段场景）
            render.mjs：无头 Chromium 驱动，逐帧截图并送入 ffmpeg
audio/      narration.py 旁白与分段；make_vo.py 合成+校对+字幕；make_music.py 配乐与音效；mix.py 混音
build.sh    一键重建（音频 → 画面 → 成片）
output/     成片、字幕、时间表
```

修改文字：屏幕字幕在 `render/js/overlay.js` 的 `CAPTIONS`；旁白在 `audio/narration.py`；各段画面在 `render/js/scenes/`。预览单帧：`cd render && node render.mjs --stills 12.5,30 --outdir ../output/stills`。
